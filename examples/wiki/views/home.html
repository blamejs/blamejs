blamejs

The Node framework that owns its stack. Zero npm runtime dependencies, post-quantum crypto from the start, sealed-by-default storage, audit chain on every operator action.

This site is the docs and a working reference app — every page you read renders through the framework's own primitives.

Quick start #

npm install @blamejs/core
node -e 'require("@blamejs/core").createApp({ dataDir: "./data" })'

Or browse the source layout of this very wiki for a full reference app:

var b = require("@blamejs/core");
var app = await b.createApp({
  dataDir: "./data",
  routes: function (router) {
    router.get("/", function (req, res) {
      b.render.htmlString(res, "<h1>Hello from blamejs</h1>");
    });
  },
});
await app.listen({ port: 3000 });

Note

blamejs targets Node.js Active LTS (24+). It uses node:sqlite, Intl.PluralRules, modern crypto primitives, and other recent built-ins. There is no transpilation step.

Concern groups #

Pick the area you're working on:

Auth & Permissions

Sessions, passkeys, OAuth, password hashing, RBAC, API keys, credential hashing.

Storage & State

SQLite + sealed columns, migrations, seeders, S3-compatible object store, queue, cache.

HTTP & Middleware

Router, CSRF, CORS, rate limiting, body parsing, compression, security headers, bot guard.

Crypto & Vault

PQC envelope (ML-KEM-1024, XChaCha20-Poly1305, SHAKE256), vault sealing, mTLS CA, signed webhooks.

Observability

Audit chain, metrics, tracing, structured logging, PII redaction.

Testing

HTTP fixtures, fake clock, fake httpClient, audit + observability captures, middleware runner.

Notify & Mail

Generic notification dispatcher with operator-supplied transports, mail with bounce processing.

i18n & Locale

Translations with CLDR plural rules, Accept-Language negotiation, Intl formatters, RTL detection.

Production Essentials

Cluster mode, external DB, scheduler, jobs, retry/backoff, backup/restore, NTP check.

Design tenets #

  • Zero npm runtime deps. Every dependency is vendored under lib/vendor/ with a manifest pinning version + license + provenance.
  • PQC from the start. ML-KEM-1024 + P-384 hybrid KEM, XChaCha20-Poly1305 cipher, SHAKE256 KDF, SLH-DSA-SHAKE-256f signatures. No classical-only fallbacks.
  • Sealed-by-default storage. Every database field except IDs / timestamps / FK references goes through vault.seal() or a derived hash.
  • Audit chain on every operator action. Login, page edit, cache clear, key rotation — all emit with the 5 W's (WHO / WHAT / WHEN / WHERE / HOW).
  • Composition over invention. Every primitive routes through existing primitives instead of reimplementing retry, timeouts, redaction, etc. The framework's job is coordination.
